Saboss Scan API v1

Authenticate with an organization API key{% if ctx.can("admin") %} (create one under API keys){% else %} (an admin can create one){% endif %}. Keys with scan access can add domains and start scans; read-only keys can list and read.

The machine-readable specification is at /api/openapi.json (OpenAPI 3).

MethodPathPurpose
GET/api/v1/domainsList domains (page, per_page ≤ 100)
POST/api/v1/domainsAdd a domain: {"hostname": "example.com", "authorized": true}
GET/api/v1/domains/{id}Get one domain
GET/api/v1/scansList scans (domain_id, status, page, per_page)
POST/api/v1/scansStart a scan: {"domain_id": 1} → 202 Accepted
GET/api/v1/scans/{id}Scan status and full report when completed
GET/api/v1/scans/{id}/report.pdfPDF report

Example

curl -s -X POST {{ base_url }}/api/v1/scans \
  -H "Authorization: Bearer $SABOSS_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"domain_id": 1}'

curl -s {{ base_url }}/api/v1/scans/42 -H "Authorization: Bearer $SABOSS_API_KEY"

Errors and limits

Errors are returned as {"error": {"code": "...", "message": "..."}} with codes such as unauthorized, forbidden, not_found, conflict, validation_error and rate_limited. Each key may make 120 requests per minute; each organization may start {{ request.app.state.settings.scans_per_org_per_hour }} scans per hour.
